Developer FAQ

How do I create my first clone operator?

Use the cohort init command to bootstrap your sovereign runtime. Provide memoir content through the CLI or web interface. Your operators will begin learning your patterns immediately while maintaining complete data isolation.

$ cohort init --memoir-path ./my-writing.md
$ cohort deploy --env development
$ cohort test-connection
What development environments are supported?

Cohort runs on any environment with Node.js 18+ support. Local development, cloud instances, edge computing, or hybrid deployments all work. The sovereign runtime ensures consistent behavior regardless of infrastructure.

  • Local: macOS, Linux, Windows
  • Cloud: AWS, GCP, Azure, Vercel
  • Edge: Cloudflare Workers, Railway
  • Containers: Docker, Kubernetes
How do I integrate Cohort with existing applications?

Use our REST API endpoints or WebSocket connections. Clone operators expose standardized interfaces while maintaining internal sovereignty. Documentation includes integration examples for popular frameworks.

// REST API Example
const response = await fetch('/api/operators/chloe/converse', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ message: 'Hello Chloe' })
});

// WebSocket Example  
const ws = new WebSocket('ws://localhost:3000/operators/stream');
ws.send(JSON.stringify({ operator: 'chloe', prompt: 'Analyze this data' }));
Can I customize operator personalities and capabilities?

Yes! Each operator can be fine-tuned with custom training data, personality parameters, and capability modules. The sovereign runtime preserves your customizations while ensuring data isolation.

Configuration options: Personality traits, response style, domain expertise, memory retention, API integrations, and custom tool access.
